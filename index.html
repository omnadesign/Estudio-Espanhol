📖 Como configurar seu Firebase gratuito em 2 minutos
  1. Acesse console.firebase.google.com, crie um projeto e registre um aplicativo Web (</>) para copiar o firebaseConfig acima.
  2. Em Authentication > Sign-in method, ative o provedor Google e adicione seu domínio (ex: seu-usuario.github.io) em Authorized domains.
  3. Em Firestore Database, crie o banco e cole esta regra de segurança:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /estudio_espanhol_progresso/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
